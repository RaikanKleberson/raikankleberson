## 👨‍💻 Sobre mim

Sou estudante de **Engenharia de Software** e fundador da **Nokaiz Tecnologia**, uma empresa de tecnologia que desenvolve soluções digitais para pequenos negócios.

Atualmente estou focado no **PedeAki Delivery**, uma plataforma SaaS de pedidos online que conecta pequenos comércios a seus clientes via WhatsApp e Pix.

- 🔭 Trabalhando no [PedeAki Delivery](https://raikankleberson.github.io/pedeaki-v1/)
- 🌱 Estudando **JavaScript**, **Node.js** e **Supabase**
- 🎯 Objetivo: Me tornar **Full Stack Developer**
- 💬 Pergunte-me sobre: **HTML, CSS, JavaScript, Git e Supabase**
